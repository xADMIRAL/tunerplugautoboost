# Vendored TunerStudio plugin API

`com/efiAnalytics/TunerStudioPluginAPI/1.0/TunerStudioPluginAPI-1.0.jar` is the unmodified
`TunerStudioPluginAPI.jar` published by EFI Analytics for plugin developers (the same copy that
ships in `<TunerStudio>/lib` and in the rusEFI repository). It is used with `provided` scope
only: the classes are never bundled into `BoostAutotune.jar`, TunerStudio supplies them at runtime.
